# Bug Investigation Skill

## Purpose

Diagnose and resolve software defects.

## Process

1. Understand symptom.
2. Reproduce.
3. Inspect logs/tests/code.
4. Identify root cause.
5. Create minimal fix.
6. Add regression test.
7. Verify.
8. Document.

## Rule

Do not hide symptoms with superficial workarounds when root cause can be identified.
