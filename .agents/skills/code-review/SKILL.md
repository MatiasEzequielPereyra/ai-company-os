# Code Review Skill

## Purpose

Review implementation changes independently before they are considered complete.

## Process

1. Inspect the requested change.
2. Understand the intended behavior.
3. Review implementation correctness.
4. Check edge cases.
5. Check tests.
6. Check maintainability.
7. Check security implications.
8. Identify regressions.
9. Report findings by severity.

## Output

Structured review findings and final review status.
