# Bug Skill

## Purpose

Investigate and resolve software defects systematically.

## Process

1. Understand the reported behavior.
2. Reproduce the issue.
3. Identify the root cause.
4. Determine affected components.
5. Implement the smallest appropriate fix.
6. Add or update regression tests.
7. Verify the fix.
8. Document relevant findings.

## Output

Root cause, implemented fix, tests, and verification results.
