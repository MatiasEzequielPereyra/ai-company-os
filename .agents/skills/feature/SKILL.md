# Feature Skill

## Purpose

Implement product features within approved requirements and architecture.

## Process

1. Understand requirements.
2. Read product and architecture documentation.
3. Inspect the existing implementation.
4. Identify affected components.
5. Implement the feature.
6. Add tests.
7. Verify acceptance criteria.
8. Report changes and remaining risks.

## Output

Implemented feature, tests, verification results, and relevant documentation updates.
