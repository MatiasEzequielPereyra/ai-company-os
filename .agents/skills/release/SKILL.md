# Release Skill

## Purpose

Prepare software for a safe release.

## Process

1. Verify implementation status.
2. Verify tests.
3. Verify quality gates.
4. Review known risks.
5. Check deployment requirements.
6. Check configuration and environment requirements.
7. Verify rollback considerations.
8. Produce release readiness assessment.

## Output

Release readiness assessment, outstanding risks, deployment requirements, and rollback considerations.
