# Architecture Skill

## Purpose

Analyze and design technical architecture.

## Process

1. Understand requirements.
2. Inspect current architecture.
3. Identify constraints.
4. Identify alternatives.
5. Evaluate tradeoffs.
6. Select approach.
7. Document decision.
8. Identify migration risks.

## Output

Architecture proposal and ADR when appropriate.
