# Execution Protocol

## Phase 1 — Understand

The CEO must understand:

- User objective.
- Current project state.
- Relevant documentation.
- Constraints.

## Phase 2 — Plan

The CEO determines:

- Required roles.
- Dependencies.
- Execution order.
- Parallel work.

## Phase 3 — Delegate

Work is delegated to the appropriate agent.

## Phase 4 — Implement

Engineering agents modify the project.

## Phase 5 — Review

Implementation is reviewed.

## Phase 6 — QA

Acceptance criteria are verified.

## Phase 7 — Security

Security review occurs when applicable.

## Phase 8 — Final Verification

CEO verifies that the original objective was satisfied.

## Rule

Never declare completion merely because implementation finished.
