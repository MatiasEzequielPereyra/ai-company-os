# Definition of Done

A task is DONE only when all applicable conditions are satisfied.

## Product

- Requirements satisfied.
- Acceptance criteria satisfied.
- Scope respected.

## Engineering

- Implementation complete.
- Code follows project conventions.
- No unrelated changes.

## Testing

- Relevant tests added or updated.
- Tests pass.
- Regression checks completed when appropriate.

## Code Quality

- Lint passes.
- Type checks pass when applicable.
- Build passes when applicable.

## Documentation

Documentation updated when behavior, architecture or operational procedures changed.

## Security

Security review completed when applicable.

## Operations

Deployment considerations verified when applicable.

## Final

No known critical blockers remain.
