# Quality Gates

## Gate 1 — Product

Required:

- Requirements defined.
- Acceptance criteria defined.
- Scope understood.

Owner:

PM

---

## Gate 2 — Architecture

Required when technical design is affected:

- Architecture reviewed.
- Contracts defined.
- Technical risks identified.

Owner:

CTO

---

## Gate 3 — Implementation

Required:

- Code implemented.
- Relevant tests created.
- Local verification completed.

Owner:

Engineering

---

## Gate 4 — Code Review

Required:

- Changes reviewed.
- Critical findings resolved.

Owner:

Reviewer

---

## Gate 5 — QA

Required:

- Acceptance criteria verified.
- Regression checks completed when applicable.
- Critical bugs resolved.

Owner:

QA

---

## Gate 6 — Security

Required when applicable:

- Security review completed.
- Critical/high findings resolved or explicitly accepted.

Owner:

Security

---

## Gate 7 — Release

Required when deployment occurs:

- Build validated.
- Deployment validated.
- Smoke tests completed.
- Monitoring verified.

Owner:

DevOps

---

## Gate 8 — Final

Required:

- Original objective satisfied.
- All applicable gates passed.
- No unresolved critical blockers.

Owner:

CEO
