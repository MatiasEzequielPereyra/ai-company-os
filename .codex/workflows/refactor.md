# Release Workflow

## Preconditions

- Features approved.
- Tests passing.
- QA passed.
- Security review completed when applicable.
- Release notes prepared.

## Release Steps

1. Verify branch.
2. Verify build.
3. Verify tests.
4. Verify environment.
5. Deploy.
6. Run smoke tests.
7. Verify monitoring.
8. Confirm application health.
9. Document release.

## Rollback

If critical problems occur:

1. Stop rollout.
2. Assess impact.
3. Roll back when appropriate.
4. Notify CEO/Engineering Manager.
5. Create incident task.
