# Feature Development Workflow

## Phase 1 — Discovery

CEO receives the request.

Determine:

- Objective
- Scope
- Type of request
- Affected systems
- Required specialists

---

## Phase 2 — Product

PM creates or validates the PRD.

Output:

docs/product/

---

## Phase 3 — Architecture

CTO analyzes the technical implications.

Output:

- Technical plan
- Architecture changes
- ADR when necessary

---

## Phase 4 — Planning

Engineering Manager:

- Creates tasks.
- Assigns owners.
- Identifies dependencies.
- Determines parallel work.

---

## Phase 5 — Implementation

Specialized agents implement tasks.

Each task must produce a handoff.

---

## Phase 6 — Review

Code is reviewed.

Review findings must be documented.

---

## Phase 7 — QA

QA validates:

- Acceptance criteria
- Functional behavior
- Regression risk

---

## Phase 8 — Security

Security reviews changes when applicable.

---

## Phase 9 — Release

DevOps handles deployment when applicable.

---

## Phase 10 — Completion

CEO verifies the original objective.

Task moves to DONE only after all applicable gates pass.
