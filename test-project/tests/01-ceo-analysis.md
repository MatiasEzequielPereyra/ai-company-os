# Test 01 — CEO Analysis

## Objective

Validate that the CEO can analyze a project without modifying it.

## Prompt

Analyze this project as CEO.

Do not modify any files.

Identify:

1. Project objective.
2. Current state.
3. Product questions.
4. Architecture questions.
5. Engineering work.
6. Risks.
7. Required agents.
8. Suggested execution order.

## Expected Behavior

The CEO should:

- Read project context.
- Understand the objective.
- Identify missing information.
- Delegate conceptually.
- Avoid implementation.
- Avoid modifying files.
