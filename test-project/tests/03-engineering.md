# Test 03 — Engineering Management

## Objective

Validate task decomposition.

## Prompt

Using the product requirements and architecture,
decompose implementation into engineering tasks.

Identify:

- Backend tasks.
- Frontend tasks.
- Infrastructure tasks.
- Testing tasks.
- Security tasks.

For each task define:

- Owner.
- Dependencies.
- Acceptance criteria.
- Parallelization opportunities.

Do not implement.
